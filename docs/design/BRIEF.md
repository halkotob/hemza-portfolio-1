# Creative brief: hemzaalkotob portfolio (v2)

Produced with the `creative-direction` skill. Every design, copy, and motion decision checks against this file. To break it, change it here first.

## Project

A personal site for Hemza Alkotob: TV and feature writer, cloud engineer at Alfa, software engineer at Masjidal, and maker of small games. Based in Detroit. University of Michigan, BS Computer Science and BA Film (screenwriting).

## Audience and goal

| Reader | Arrives wanting | Leaves having |
| --- | --- | --- |
| Managers, producers, fellowship and contest readers | Proof he can write | Read page one of a script, ideally the first ten |
| Cloud and software hiring managers | Proof he can run real systems | Seen true numbers and opened the résumé |
| Collaborators and friends | A way in | Played IslamDunk or sent an email |

Business goal: more people read the first page of a script, and more hiring conversations start. A visitor should be reading Hemza's actual writing within five seconds of arriving.

## The four axes

1. **Tone: Conversational.** First person, contractions, plain words. Writer portfolios and engineer portfolios both default to puffed-up self-description. Plain talk stands out in both.
2. **Aesthetic: Controlled maximalist, in one place only.** The script page is the loud element: big, real, set exactly the way a screenplay is set. Everything around it stays quiet and disciplined. (Spend the boldness in one place, per `frontend-design`.)
3. **Audience relationship: Peer.** He talks to a reader the way one writer talks to another, and to an engineer the way a teammate would. No "I'm passionate about…", and no coaching or lecturing.
4. **Sensory ambition: Considered.** Craft is visible, but reading and contacting come first. A first page that reads like a real script page is the only "moment".

Tension to watch: maximalist and peer can drift into showing off. The fix is that the bold thing is his own writing, not decoration.

## Synthesis

The site is a reading desk. The first thing on screen is the opening page of a script, set correctly in 12-point Courier with real screenplay margins. Revision paper colors mark which script you're reading, the way a production marks revised pages. Around that page, the site reads like a note from a person: short, specific, with true numbers about the engineering work and no decorative chrome. The visual language comes from production paperwork (paper stock, revision colors, page numbers, pen notes), not from any web template.

## Subject vernacular (where the choices come from)

- **Revision colors.** Productions print revised script pages on colored stock in a fixed order: white, blue, pink, yellow, green, goldenrod. That is a real sequence, so the order carries meaning. Each script gets one color.
- **Courier 12pt** is the required screenplay face. Use it only for screenplay text, the real artifact. Never use it for labels or chrome.
- **Ballpoint blue** is the color of notes in the margin. It marks actions (links, buttons): the reader's next move.
- **Page numbers** sit top right with a period ("1."), as on a real script page.

## Explicit exclusions (checked by `avoid-ai-design`)

- No dark mode, no near-black ground with one neon accent (SD2), no cream with terracotta (SD1).
- No all-caps eyebrows, no middle-dot meta strings, no mono labels (SD4).
- No fake browser window chrome (SD7). Show the real game.
- No stat strip (L4). True numbers live inside sentences.
- No centered hero (L1), no identical card grid (L2), no section waterfall (L9).
- No one-word headline accents (SD5), no decorative 01/02/03 (SD6).
- No reflexive backdrop blur (K3), no colored left-border cards (K4).
- None of the previous site's motifs: comic book, Damascene pattern, Arabic signature, green/orange palette.
